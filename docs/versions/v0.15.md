# Version 0.15.0 — Observability & Real-Time Telemetry

## 1. Objective
Implement distributed turn span tracing and Prometheus metrics exposition (`/metrics`) to observe real-time latency across audio ingestion, VAD, STT, LLM TTFT, tool calling, and TTS TTFA.

---

## 2. Changes Implemented
- **Telemetry Module (`backend/app/observability/telemetry.py`)**:
  - `TurnSpan`: Captures granular latencies per turn.
  - `MetricsExporter`: In-memory aggregator generating Prometheus exposition format.
- **REST APIs (`backend/app/api/endpoints.py`)**:
  - `GET /metrics`: Prometheus metric scrape endpoint.
- **Automated Test Suite (`backend/tests/test_observability.py`)**:
  - Validates turn span completion and `/metrics` output.
