# Version 0.13.0 — Agent Tools & Actions

## 1. Objective
Implement an Agent Tools & Actions framework enabling the AI interviewer to execute Python code snippets in a timed sandbox, generate live system architecture diagrams, query official technical documentation, and log flags for human recruiter review.

---

## 2. Previous Architecture (v0.12.0)
- The system supported Knowledge Base RAG, answer evaluation, and cross-turn memory.
- However, the interviewer could not execute candidate code, generate visual architecture diagrams, or look up authoritative engine specifications.

---

## 4. Changes Implemented
- **Tool Models (`backend/app/models/tools.py`)**:
  - `ToolCall`, `ToolResult`, `ArchitectureDiagramPayload`, `CodeExecutionPayload`, `DocumentationLookupPayload`, `HumanFlagPayload`.
- **Tool Executor (`backend/app/agent/tools/executor.py`)**:
  - `execute_python_sandbox`: Safely evaluates candidate Python snippets with timeout and captures stdout/stderr.
  - `generate_architecture_diagram`: Synthesizes Mermaid syntax and node topologies.
  - `lookup_documentation`: Authoritative engine reference queries (PostgreSQL MVCC, Kafka rebalances, Redis clustering).
  - `flag_for_human_review`: Logs flags for recruiter audit.
- **REST APIs & WebSockets (`backend/app/api/endpoints.py`)**:
  - `GET /api/agent/tools`
  - `POST /api/agent/tools/execute`
  - WebSocket emits `tool_executed` event.
- **Frontend UI (`frontend/src/components/VoiceRoom.tsx`, `index.css`)**:
  - "🛠️ Architecture & Tools" tab in Scorecard modal.
  - System architecture diagram viewer with node badges.
  - Interactive Python Sandbox code editor and execution console.
- **Automated Test Suite (`backend/tests/test_agent_tools.py`)**:
  - 56 total automated tests passing.
