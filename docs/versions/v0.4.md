# Version 0.4.0 — Natural Turn Taking

## 1. Objective
Enable human-like conversational turn-taking by implementing Voice Activity Detection (VAD), speech start/end detection, configurable silence thresholding, and intelligent endpointing that distinguishes candidate thinking pauses from completed answers.

---

## 2. Previous Architecture (v0.3.0)
- Streaming voice pipeline was reliant on external turn signals or single-shot audio payloads.
- No dynamic detection of when speech started or when pauses occurred within a sentence.

---

## 3. New Architecture (v0.4.0)
```
┌────────────────────────────────────────────────────────────┐
│                  Frontend (React / Vite)                   │
│  - Live VAD State Pill (🟢 Speaking / 🟡 Paused / 🟣 End)  │
│  - Silence Threshold Slider (400ms - 1600ms)               │
└─────────────────────────────┬──────────────────────────────┘
                              │ Audio Frames (PCM16)
┌─────────────────────────────▼──────────────────────────────┐
│                    Turn Detector & VAD                     │
│                                                            │
│   Incoming Frames ──► Energy / RMS VAD (Adaptive Noise)    │
│                               │                            │
│                               ▼                            │
│   State Machine:                                           │
│   ├── Speech Detected   ──► CANDIDATE_SPEAKING             │
│   ├── Pause (< 600ms)   ──► CANDIDATE_PAUSED (Agent Waits) │
│   └── Silence (≥ 800ms) ──► TURN_ENDPOINT Triggered        │
└─────────────────────────────┬──────────────────────────────┘
                              │
┌─────────────────────────────▼──────────────────────────────┐
│                  Streaming Voice Pipeline                  │
│       STT ──► LLM Token Stream ──► Streaming TTS           │
└────────────────────────────────────────────────────────────┘
```

---

## 4. Changes Implemented
- **VAD Provider Layer (`backend/app/voice/vad/`)**:
  - `BaseVADProvider`, `VADFrameResult`, `VADState`.
  - `EnergyVADProvider` with RMS calculation and exponential moving average (EMA) noise floor adaptation.
  - `MockVADProvider` for deterministic testing.
- **Turn Detector State Machine (`backend/app/voice/vad/turn_detector.py`)**:
  - Distinguishes intra-turn thinking pauses from true answer completion.
  - Rejects brief spurious microphone noises (< 250ms).
- **Telemetry Enhancements (`backend/app/core/telemetry.py`)**:
  - Added `speech_duration_ms`, `pause_count`, and `endpointing_delay_ms`.
- **API Endpoints (`backend/app/api/endpoints.py`)**:
  - Added `POST /api/voice/vad/process` for real-time PCM audio frame evaluation.
  - Emits real-time `vad_event` over `/api/voice/stream/ws`.
- **Frontend UI (`frontend/src/components/VoiceRoom.tsx`)**:
  - Live VAD state indicator pill (`🟢 Speaking`, `🟡 Thinking Pause`, `🟣 Turn Endpoint`, `⚪ Idle`).
  - Interactive silence threshold slider.
- **Automated Test Suite (`backend/tests/test_vad_turn_detection.py`)**:
  - 16 total automated tests passing.
