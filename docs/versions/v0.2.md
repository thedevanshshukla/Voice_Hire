# Version 0.2.0 — Basic Voice Pipeline

## 1. Objective
Establish the foundational voice pipeline for VoiceHire by implementing modular provider abstractions for STT, LLM, and TTS, LiveKit JWT session token generation, turn execution with per-stage latency telemetry, and an interactive frontend Voice Room interface.

---

## 2. Previous Architecture (v0.1.0)
- Monorepo foundation with FastAPI backend and React/Vite frontend.
- `/health` endpoint and static UI status dashboard.
- No audio processing or AI provider integrations.

---

## 3. New Architecture (v0.2.0)
```
┌────────────────────────────────────────────────────────┐
│               Frontend (React / Vite)                  │
│  - Live VoiceRoom with Audio Waveform Visualizer       │
│  - Realtime Transcript Feed with Latency Breakdown     │
└───────────────────────────┬────────────────────────────┘
                            │ REST / WebRTC Token
┌───────────────────────────▼────────────────────────────┐
│                  FastAPI Backend                       │
│  - POST /api/voice/token (LiveKit JWT AccessToken)     │
│  - POST /api/voice/turn  (STT -> LLM -> TTS pipeline)  │
│  - GET  /api/voice/status (Provider health & config)   │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│             Voice Provider Abstractions                │
│  ├── STT: BaseSTTProvider (Mock, Deepgram)             │
│  ├── LLM: BaseLLMProvider (Mock, OpenAI, Gemini)       │
│  └── TTS: BaseTTSProvider (Mock, ElevenLabs, Deepgram) │
└────────────────────────────────────────────────────────┘
```

---

## 4. Changes Implemented
- **Voice Abstractions (`backend/app/voice/`)**:
  - `stt/base.py`, `llm/base.py`, `tts/base.py`
  - Pluggable provider implementations for Mock, Deepgram, OpenAI, Gemini, ElevenLabs.
  - `VoiceProviderFactory` for dynamic dependency injection.
- **Pipeline Orchestrator (`backend/app/voice/pipeline.py`)**:
  - Turn coordinator executing `Audio In -> STT -> LLM -> TTS -> Audio Out`.
  - Latency instrumentation (`stt_latency_ms`, `llm_latency_ms`, `tts_latency_ms`, `total_latency_ms`).
- **LiveKit Agent & Token API (`backend/app/agent/` & `backend/app/api/endpoints.py`)**:
  - Signed JWT token generator with `room_join` & `can_publish` grants.
  - REST endpoints: `/api/voice/token`, `/api/voice/turn`, `/api/voice/status`.
- **Frontend VoiceRoom (`frontend/src/components/VoiceRoom.tsx`)**:
  - Room initialization and participant token acquisition.
  - Dynamic audio visualizer with multi-state animations (`listening`, `thinking`, `speaking`).
  - Realtime conversation stream showing candidate & interviewer bubbles and latency badges.
- **Automated Test Suite (`backend/tests/`)**:
  - 9 automated unit and API integration tests covering all providers, factory, pipeline, and endpoints.
