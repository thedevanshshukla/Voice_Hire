# Version 0.17.0 — Evaluation Suite & Benchmark Runner

## 1. Objective
Implement an automated evaluation benchmark suite and scoring calibration runner comparing AI interviewer grading accuracy (MAE) and red flag detection against human-calibrated golden standard datasets.

---

## 2. Changes Implemented
- **Benchmark Models (`backend/app/models/benchmark.py`)**:
  - `GoldenInterviewSample`, `SampleEvaluationResult`, `BenchmarkRunSummary`.
- **Benchmark Runner (`backend/app/evaluation/benchmark_runner.py`)**:
  - Pre-seeded golden dataset across SDE-1, SDE-2, Senior, and Staff transcripts.
  - Automated scoring calibration engine computing MAE, accuracy percentage, and red flag precision/recall.
- **REST APIs (`backend/app/api/endpoints.py`)**:
  - `POST /api/evaluation/run-benchmark`
  - `GET /api/evaluation/benchmark-results`
- **Automated Test Suite (`backend/tests/test_benchmark_suite.py`)**:
  - Tests benchmark execution and metric tolerances (MAE < 1.0, accuracy >= 75%).
