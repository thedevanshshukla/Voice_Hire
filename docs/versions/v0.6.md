# Version 0.6.0 — Interview Foundation

## 1. Objective
Transform the generic realtime voice pipeline into **VoiceHire: The AI Technical Interviewer**. Introduce interview domain models, role configurations, seniority levels, topic multi-selection, contextual prompt generation, and MongoDB session persistence.

---

## 2. Previous Architecture (v0.5.0)
- Streaming voice pipeline with VAD turn taking and barge-in audio cutoff.
- Agent operated on generic conversational prompts without interview role configurations, structured question domains, or database session persistence.

---

## 3. New Architecture (v0.6.0)
```
┌────────────────────────────────────────────────────────────┐
│                  Frontend (React / Vite)                   │
│  - Interview Setup Wizard (Role, Level, Topics, JD)        │
│  - Past Sessions Drawer & Voice Room Active Session View   │
└─────────────────────────────┬──────────────────────────────┘
                              │ POST /api/interview/session
┌─────────────────────────────▼──────────────────────────────┐
│                    FastAPI Backend                         │
│  ├── Contextual Prompt Builder                             │
│  │   (Injects Role, Level, Topics, JD, Conversational Rules)│
│  └── Interview Session Repository                          │
└──────────────┬──────────────────────────────┬──────────────┘
               │                              │
┌──────────────▼─────────────┐ ┌──────────────▼──────────────┐
│       MongoDB Atlas        │ │   Streaming Voice Pipeline  │
│  - interview_sessions doc  │ │   - Injects System Prompt   │
│  - Transcripts & Telemetry │ │   - Live Voice Turn Taking  │
└────────────────────────────┘ └─────────────────────────────┘
```

---

## 4. Changes Implemented
- **Interview Domain Models (`backend/app/models/interview.py`)**:
  - `InterviewRole`: Backend, Frontend, Fullstack, DevOps/SRE, Systems Architect.
  - `ExperienceLevel`: SDE-1, SDE-2, Senior, Staff.
  - `InterviewTopic`: DBMS, OS, Networking, System Design, Caching, Distributed Systems, APIs, Queues.
  - `InterviewConfig`, `TranscriptEntry`, `SessionStatus`, and `InterviewSession`.
- **Database Persistence (`backend/app/db/mongo.py`)**:
  - Async Motor MongoDB collection (`interview_sessions`) with in-memory fallback.
- **Contextual Prompt Builder (`backend/app/interview/prompt_builder.py`)**:
  - Automatically synthesizes system prompts enforcing voice conciseness, role-calibrated technical depth, and JD requirements.
- **API Endpoints (`backend/app/api/endpoints.py`)**:
  - Added `GET /api/interview/templates`, `POST /api/interview/session`, `GET /api/interview/session/{session_id}`, `GET /api/interview/sessions`.
- **Frontend UI (`frontend/src/components/InterviewSetup.tsx`)**:
  - Role selection cards, seniority badges, topic chips, custom JD input, language selector, duration picker, and past interview history drawer.
- **Automated Test Suite (`backend/tests/test_interview_foundation.py`)**:
  - 24 total automated tests passing.
