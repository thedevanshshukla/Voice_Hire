# Version 0.7.0 — Interview State Machine

## 1. Objective
Implement a multi-stage finite state machine governing the technical interview arc: `GREETING -> RESUME_DEEP_DIVE -> CORE_CONCEPTS -> SYSTEM_DESIGN -> CANDIDATE_QUESTIONS -> WRAP_UP`. Manage stage time budgets, transition criteria, dynamic prompt directives, and frontend progress visualization.

---

## 2. Previous Architecture (v0.6.0)
- Interview sessions were configured with role, level, topics, and JD, but the conversation proceeded without structured stages or stage-based time management.

---

## 3. New Architecture (v0.7.0)
```
┌─────────────────────────────────────────────────────────────────────────┐
│                        Frontend (React / Vite)                          │
│  - 6-Stage Visual Timeline [Intro > Projects > Core > System > Q&A > End]│
│  - Real-time Stage Transition Notifications                             │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
┌────────────────────────────────────▼────────────────────────────────────┐
│                       Interview State Machine                           │
│                                                                         │
│   Turn Event ──► Evaluate Stage Turn Budget & Time Allocation           │
│              ──► Transition to Next Stage if Criteria Met               │
│              ──► Generate Stage-Specific Prompt Directive               │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ Injects Stage Directive
┌────────────────────────────────────▼────────────────────────────────────┐
│                    Contextual Prompt Builder                            │
│    (Combines Role, Level, Topics, JD + Active Stage Directive)          │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │
┌────────────────────────────────────▼────────────────────────────────────┐
│                   Streaming Voice AI Pipeline                           │
│        Candidate Audio ──► VAD ──► STT ──► LLM ──► TTS Audio            │
└─────────────────────────────────────────────────────────────────────────┘
```

---

## 4. Changes Implemented
- **State Machine Engine (`backend/app/interview/state_machine.py`)**:
  - `InterviewStage` enum with 6 distinct phases.
  - Proportional time budgeting (10% Greeting, 20% Resume, 35% Core Concepts, 25% System Design, 7% Q&A, 3% Wrap-up).
  - `InterviewStateMachine` managing turn counts, transition evaluations, and stage directives.
- **Stage Prompt Conditioning (`backend/app/interview/prompt_builder.py`)**:
  - Injects stage-specific behavioral rules into the interviewer system prompt.
- **Model & Database Updates (`backend/app/models/interview.py`)**:
  - Added `current_stage`, `stage_turn_counts`, and per-transcript `stage` tagging.
- **API & WebSocket Integration (`backend/app/api/endpoints.py`)**:
  - Added `GET /api/interview/stages` returning stage budget breakdowns.
  - Emits `stage_transition` WebSocket events upon stage advancement.
- **Frontend UI (`frontend/src/components/VoiceRoom.tsx`)**:
  - Interactive 6-stage step progression timeline with active step highlight, completion checkmarks, and percentage completion.
- **Automated State Machine Test Suite (`backend/tests/test_interview_state_machine.py`)**:
  - 28 total automated tests passing.
