# Version 0.5.0 — Interruption & Barge-in

## 1. Objective
Implement natural interruption / barge-in support allowing candidates to speak over the AI interviewer. The system halts active TTS synthesis and LLM generation in real time (< 200ms latency), clears audio playback buffers, and immediately transitions into listening mode.

---

## 2. Previous Architecture (v0.4.0)
- Natural turn taking was supported for candidate speech and pause endpointing.
- However, if the agent was speaking, candidate speech could not interrupt the ongoing audio stream until the agent finished its complete turn.

---

## 3. New Architecture (v0.5.0)
```
┌────────────────────────────────────────────────────────────┐
│                  Frontend (React / Vite)                   │
│  - Instant Audio Buffer Cutoff on Candidate Speech         │
│  - Red Interruption Badge & Manual Barge-In Trigger        │
└─────────────────────────────┬──────────────────────────────┘
                              │ Audio Frames / WS Interrupt
┌─────────────────────────────▼──────────────────────────────┐
│                     Barge-In Detector                      │
│                                                            │
│   Incoming Audio (during Agent Output)                     │
│   ├── If Candidate Speech (≥ 120ms)                        │
│   └── ──► Trigger CancellationToken.cancel()               │
└─────────────────────────────┬──────────────────────────────┘
                              │ Abort Signal (< 50ms)
┌─────────────────────────────▼──────────────────────────────┐
│                  Streaming Voice Pipeline                  │
│   ├── Abort LLM Token Stream                               │
│   ├── Abort Streaming TTS Synthesis                        │
│   └── Emit `interrupted` Event & Clear Buffers             │
└────────────────────────────────────────────────────────────┘
```

---

## 4. Changes Implemented
- **Cancellation Pattern (`backend/app/voice/interruption/cancellation.py`)**:
  - `CancellationToken` supporting async cooperative abortion across token generator loops and TTS chunk streams.
- **Barge-In Detector (`backend/app/voice/interruption/barge_in.py`)**:
  - Monitors candidate audio frames during `SPEAKING` / `THINKING` states and triggers sub-200ms cancellation upon speech detection.
- **Telemetry Enhancements (`backend/app/core/telemetry.py`)**:
  - Added `interrupted`, `interruption_count`, `interruption_detection_ms`, `cancellation_latency_ms`, and `interrupted_at_word`.
- **API & WebSocket Integration (`backend/app/api/endpoints.py`)**:
  - Full WebSocket support for real-time barge-in command and `interrupted` event broadcasts.
- **Frontend UI (`frontend/src/components/VoiceRoom.tsx`)**:
  - Instant audio element pausing and buffer clearing.
  - Live Interruption banner and barge-in action buttons.
- **Automated Interruption Test Suite (`backend/tests/test_interruption.py`)**:
  - 19 total automated tests passing.
