# Version 0.14.0 — Multilingual Support (English + Hindi + Hinglish)

## 1. Objective
Implement multilingual voice interviewing supporting English, pure Hindi (Devanagari script), and natural tech "Hinglish" (conversational Hindi with strict English technical vocabulary preservation) alongside real-time dynamic code-switching detection.

---

## 2. Previous Architecture (v0.13.0)
- The system supported agent tool calling, sandboxed code execution, and architecture diagrams.
- However, prompts and voice pipelines operated primarily in English with basic static Hindi prompt flags, lacking real-time code-switching detection and specialized Hinglish technical vocabulary preservation.

---

## 4. Changes Implemented
- **Multilingual Detection Module (`backend/app/voice/multilingual.py`)**:
  - `LanguageDetector`: Detects pure English, Devanagari Hindi, and Romanized Hinglish vocabulary (`humne`, `karega`, `koshish`, `kyunki`, `hota hai`).
  - Provider model configuration routing (`nova-2 multi`, `eleven_multilingual_v2`).
- **Prompt Grounding (`backend/app/interview/prompt_builder.py`)**:
  - Injects `[LANGUAGE DIRECTIVE]` preserving English technical terminology while framing natural conversational dialogue in Hinglish.
- **REST APIs & WebSockets (`backend/app/api/endpoints.py`)**:
  - `POST /api/voice/detect-language`: Returns language classification and confidence.
  - WebSocket emits `language_switched` event.
- **Frontend UI (`frontend/src/components/InterviewSetup.tsx`, `VoiceRoom.tsx`, `index.css`)**:
  - Language selector with English, Hindi, and Hinglish options.
  - Live Language HUD pill in VoiceRoom.
- **Automated Test Suite (`backend/tests/test_multilingual.py`)**:
  - 62 total automated tests passing.
