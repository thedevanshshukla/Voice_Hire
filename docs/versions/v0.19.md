# Version 0.19.0 — Scale & Concurrent Load Testing

## 1. Objective
Implement a multi-room concurrent synthetic load benchmark harness simulating parallel interview rooms and computing P50/P95/P99 latency distributions and throughput.

---

## 2. Changes Implemented
- **Scale Models (`backend/app/models/scale.py`)**:
  - `LoadTestConfig`, `LoadTestResult`.
- **Load Runner (`backend/app/scale/load_runner.py`)**:
  - `ConcurrentLoadSimulator`: Executes parallel worker tasks against the voice pipeline and computes latency percentiles and throughput (TPS).
- **REST APIs (`backend/app/api/endpoints.py`)**:
  - `POST /api/scale/run-load-test`
  - `GET /api/scale/load-test-results`
- **Automated Test Suite (`backend/tests/test_scale_load.py`)**:
  - Validates concurrent load simulation and percentiles.
