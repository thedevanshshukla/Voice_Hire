# Version 0.11.0 — Knowledge Base & RAG Engine

## 1. Objective
Implement a company knowledge base ingestion and mid-interview Retrieval-Augmented Generation (RAG) engine allowing interviewers to ground questions and candidate answer verification in official company engineering standards, custom question banks, and job rubrics.

---

## 2. Previous Architecture (v0.10.0)
- VoiceHire evaluated answers and extracted quote evidence.
- However, evaluations relied on generalized LLM knowledge without grounding in company-specific engineering standards, question banks, or proprietary rubrics.

---

## 4. Changes Implemented
- **Knowledge Models (`backend/app/models/knowledge.py`)**:
  - `KnowledgeCategory` (`COMPANY_STANDARDS`, `QUESTION_BANK`, `ARCHITECTURE_PATTERNS`, `JOB_RUBRIC`).
  - `KnowledgeDocument`: Ingestion model for custom guidelines and rubrics.
  - `KnowledgeSearchResult`: Retrieval match model with relevance scoring.
- **RAG Engine (`backend/app/knowledge/rag_engine.py`)**:
  - Pre-seeded with standards: Stripe Idempotency, Netflix EVCache, Uber Resilience, Meta Sharding, and Postgres Migrations.
  - Semantic keyword and tag matching algorithm.
- **Prompt Grounding (`backend/app/interview/prompt_builder.py`)**:
  - Injects `[OFFICIAL COMPANY ENGINEERING STANDARD & RAG CONTEXT]` into LLM prompts.
- **REST APIs (`backend/app/api/endpoints.py`)**:
  - `GET /api/knowledge/documents`
  - `POST /api/knowledge/ingest`
  - `POST /api/knowledge/search`
- **Frontend UI (`frontend/src/components/InterviewSetup.tsx`, `VoiceRoom.tsx`, `index.css`)**:
  - Knowledge Base Drawer in Setup Wizard.
  - Live RAG Context Badge in VoiceRoom HUD.
- **Automated Test Suite (`backend/tests/test_knowledge_rag.py`)**:
  - 45 total automated tests passing.
