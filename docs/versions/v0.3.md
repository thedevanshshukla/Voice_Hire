# Version 0.3.0 — Realtime / Streaming Pipeline

## 1. Objective
Upgrade VoiceHire from batch turn-taking to a continuous, ultra low-latency streaming pipeline featuring concurrent sentence-chunked TTS synthesis, Time-to-First-Token (TTFT) and Time-to-First-Audio (TTFA) telemetry, and WebSocket event streaming.

---

## 2. Previous Architecture (v0.2.0)
- Monolithic turn execution: STT -> Full LLM response -> Full TTS synthesis -> Audio delivery.
- Perceived latency: Cumulative sum of full STT + full LLM + full TTS (often 2.0s - 4.0s).

---

## 3. New Architecture (v0.3.0)
```
┌────────────────────────────────────────────────────────────┐
│                  Frontend (React / Vite)                   │
│  - Realtime Token Typewriter Stream                        │
│  - Live Latency HUD (TTFT / TTFA / Perceived Turnaround)   │
└─────────────────────────────┬──────────────────────────────┘
                              │ WebSocket (/api/voice/stream/ws)
┌─────────────────────────────▼──────────────────────────────┐
│                   Streaming Voice Pipeline                 │
│                                                            │
│   Audio Stream ──► Streaming STT ──► Final Transcript      │
│                                            │               │
│                                            ▼               │
│   Token Stream ◄── LLM Token Generator (TTFT Tracked)      │
│        │                                                   │
│        ▼                                                   │
│   Sentence Chunker (. ! ? \n)                              │
│        │                                                   │
│        ▼                                                   │
│   Streaming TTS (TTFA Tracked) ──► Audio Chunks Output     │
└────────────────────────────────────────────────────────────┘
```

---

## 4. Changes Implemented
- **Streaming Pipeline (`backend/app/voice/streaming_pipeline.py`)**:
  - Continuous streaming turn coordinator emitting `token`, `audio_chunk`, `metrics`, and `done` events.
- **Sentence Boundary Chunker (`backend/app/voice/chunker.py`)**:
  - Emits natural linguistic clauses so TTS synthesis overlaps with ongoing LLM token generation.
- **Latency Telemetry Tracker (`backend/app/core/telemetry.py`)**:
  - Granular instrumentation for `stt_latency_ms`, `llm_ttft_ms`, `tts_ttfa_ms`, and `total_perceived_ms`.
- **WebSocket Streaming API (`backend/app/api/endpoints.py`)**:
  - `WebSocket /api/voice/stream/ws` for full-duplex conversational sessions.
- **Frontend Voice Room Streaming (`frontend/src/components/VoiceRoom.tsx`)**:
  - Live typewriter text streaming.
  - Latency HUD with live TTFT / TTFA / Perceived latency readouts.
- **Automated Test Suite (`backend/tests/test_streaming_pipeline.py`)**:
  - 12 total unit and integration tests passing.

---

## 5. Verification & Results
- **Backend Test Suite**: 12/12 tests passed in `3.44s`.
- **Frontend Build**: Compiled 17 modules in `195ms`.
- **Latency Profiling**:
  - Mock Mode: TTFT `~20ms`, TTFA `~40ms`, Total Perceived `~80ms`.
  - Cloud Providers (Deepgram + OpenAI + ElevenLabs): Perceived latency reduced by > 50% compared to batch execution.
