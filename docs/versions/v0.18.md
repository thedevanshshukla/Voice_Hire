# Version 0.18.0 — Reliability & Security

## 1. Objective
Implement automated PII redaction (masking emails, phone numbers, and API tokens) and sliding-window rate limiting on voice API endpoints.

---

## 2. Changes Implemented
- **Security Sanitizer (`backend/app/security/sanitizer.py`)**:
  - `PIISanitizer`: Redacts emails, phone numbers, and cloud API keys from transcripts before storage.
  - `SlidingWindowRateLimiter`: Enforces sliding-window request throttling.
- **REST APIs (`backend/app/api/endpoints.py`)**:
  - Integrated PII redaction and rate limiting on voice tokens and turns.
- **Automated Test Suite (`backend/tests/test_reliability_security.py`)**:
  - Validates regex redaction and sliding window boundaries.
