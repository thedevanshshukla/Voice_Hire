# Version 0.16.0 — Voice AI Experimentation (A/B Testing)

## 1. Objective
Implement an online A/B testing and experimentation framework to scientifically compare LLM providers, TTS engines, and audio chunking algorithms across live interview latencies and candidate scoring outcomes.

---

## 2. Changes Implemented
- **Experiment Models (`backend/app/models/experiments.py`)**:
  - `ExperimentConfig`, `ExperimentVariant`, `ExperimentResult`, `VariantPerformance`.
- **A/B Manager (`backend/app/experiments/ab_engine.py`)**:
  - Pre-seeded experiments for LLM and TTS comparisons.
  - Deterministic session hash variant allocator.
  - Metrics tracking across TTFT, turn latency, and scorecard scores.
- **REST APIs (`backend/app/api/endpoints.py`)**:
  - `GET /api/experiments/active`
  - `POST /api/experiments/configure`
  - `GET /api/experiments/{exp_id}/results`
- **Automated Test Suite (`backend/tests/test_experiments.py`)**:
  - Tests variant assignment and metric aggregation.
