# Version 0.8.0 — Adaptive Question Engine

## 1. Objective
Implement dynamic, non-static technical question generation: analyze candidate response depth in real time, probe shallow or vague keyword drops (e.g. cache stampede, TTL expiry spikes, index selectivity, locking mechanisms), escalate difficulty on strong answers, and rotate systematically across configured focus topics.

---

## 2. Previous Architecture (v0.7.0)
- 6-stage interview progression with stage time budgeting.
- However, questioning within each stage relied purely on general stage directives without explicit answer depth classification or dynamic follow-up probing.

---

## 4. Changes Implemented
- **Adaptive Question Engine (`backend/app/interview/adaptive_engine.py`)**:
  - `AnswerDepth` enum (`SHALLOW_OR_VAGUE`, `MODERATE`, `STRONG_OR_COMPREHENSIVE`, `INCORRECT_OR_CONFUSED`).
  - `AdaptiveStrategy` enum (`PROBE_DEEPER`, `INCREASE_DIFFICULTY`, `PIVOT_NEXT_TOPIC`, `PROVIDE_HINT`).
  - Specialized domain probes for Caching/Redis, DBMS Indexing/MVCC, Concurrency/Deadlocks, Kafka/Queues, and Sharding/2PC.
  - Automated topic rotation when depth threshold is achieved.
- **Contextual Prompt Integration (`backend/app/interview/prompt_builder.py`)**:
  - Dynamically passes `[ADAPTIVE DIRECTIVE]` to the active LLM turn prompt.
- **Model & Database Updates (`backend/app/models/interview.py`)**:
  - Added `evaluated_depth` and `adaptive_strategy` to `TranscriptEntry`.
  - Added `topic_coverage` statistics to `InterviewSession`.
- **API & WebSocket Integration (`backend/app/api/endpoints.py`)**:
  - Added real-time `adaptive_action` WebSocket events and REST turn payload fields.
- **Frontend UI (`frontend/src/components/VoiceRoom.tsx`)**:
  - Live Adaptive Strategy pill in HUD with real-time feedback.
- **Automated Test Suite (`backend/tests/test_adaptive_engine.py`)**:
  - 32 total automated tests passing.
